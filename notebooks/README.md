# Notebooks Colab

Sube la carpeta `notebooks/` a GitHub. En Colab:

1. Abre el `.ipynb` desde GitHub o súbelo.
2. Entorno de ejecución → Ejecutar todo.

No hace falta la carpeta `data/`. Cada notebook carga sklearn (`load_breast_cancer`, `load_wine`, `load_iris`, `make_blobs`) y trae `enjambre.py` pegado en la primera celda de código.

| Archivo | Ejercicio |
|---|---|
| 01_abc_feature_selection.ipynb | ABC columnas |
| 02_pso_hyperparameter_tuning.ipynb | PSO perillas SVM |
| 03_pso_entrenar_red.ipynb | red sin backprop |
| 04_pso_clustering.ipynb | clustering |

Los `.py` equivalentes siguen en `codes/`.
